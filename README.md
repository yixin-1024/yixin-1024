### Louie

后端 / 全栈工程师。

最近在折腾的东西是给 agent 打电话。手机拨 8888，进的就是系统自带的通话界面，
然后说你要它干什么。活干完的时候你要还在线，它会在通话里插播结果；等不及先挂了也行，
下次打进来听补报。

不过它还不会主动打回来。挂断以后，得你自己再拨一次。

听着像个玩具，做起来全是脏活——外放漏回麦克风的回声只有 -30dB，微弱到我自己都听不见，
它却当成有人插话，三百毫秒内把自己掐了。这种事修完一堆，它才算能在车里用。

平时做的大多是这类活：让 agent 把事干完，并且能拿出证据证明干完了。

**[cc-lark](https://github.com/yixin-1024/feishu-claude-code)** · Python
把 IM 群聊当成 Agent 的工作台。一条需求可以派出多个独立子任务并行跑，主会话这一轮结束了它们还活着，
完工自动把结果贴回原话题；也支持让不同厂商的模型互相复核——一个实现，另一个回到真实环境查证。

**CarVoice**
用手机系统自带的拨号器打给 Agent。拨进去就是原生通话界面，用说的派任务；跑完结果在通话中插播，
先挂断的话下次来电补报。Android 原生音频链路手写，双工、打断、重采样都在里面。

**合规与支付场景的自动化** · 工作项目
在一家持牌跨境支付平台，把原本跨部门人工周转的流程做成群里一句话触发的自执行流水线：
反洗钱筛查、多币种账户开立、虚拟卡发行、账目双向对账。另外做过聊天记账与多币种复式账本。

更早：嵌入式（Wi-Fi 6 芯片协议栈、固件与系统级测试）、企业级 IM 的微服务链路、
几个 Web3 产品（预测市场的撮合与做市、双链社交应用、一个稳定币协议）。
